[관리자 - 홈]	
"QA 대시보드"
■ 페이지 설명
관리자가 로그인 직후 처음 마주하는 홈 화면.
콜센터 전체의 품질 현황을 한 페이지에 압축해 보여준다.
실시간 KPI·추세·점수 분포·긴급 이슈를 한눈에 파악해
‘오늘 어디부터 확인해야 하는가’를 판단하게 하는 진입점이며,
각 카드/차트는 클릭 시 통합 평가 현황 등 상세 화면으로 드릴다운된다.

■ 주요 기능
• 실시간 품질 KPI 4종 카드 제공 (평가 건수·평균 점수·상담시간·이슈 콜)
• 기간/센터/팀 필터 기반 품질 추세 라인 차트 표시
• 팀별 평균 점수 바 차트 제공 (채널 I/B·O/B 필터)
• 관리자 확인 영역 (긴급 이슈·FAIL·기준미달 건수)
• 점수 분포 도넛 차트 (우수/양호/주의/미달 구간)
• 최다 감점 항목 TOP 5 / 최다 감점 콜 TOP 5 테이블"
통합 평가 현황	"■ 페이지 설명
AI 자동 평가와 사람이 수행한 수동 평가 결과를
하나의 테이블에서 함께 조회·분석하는 평가 결과 탐색의 메인 작업 공간.
다양한 필터로 원하는 평가 건을 좁혀가며 살펴보고,
행 클릭으로 개별 콜의 평가 상세로 들어갈 수 있다.
‘상세 분석’ 탭에서는 센터 > 팀 > 상담사 순으로 드릴다운하며
조직별 품질 편차를 추적한다.

■ 주요 기능
• 자동·수동 평가를 단일 화면에서 통합 조회 (전체/상세 분석 탭)
• 검색 필터 제공 (센터·팀·기간·상담사·점수·통화유형·평가방식·이슈)
• 평가 결과 테이블 (평가ID·일시·소속·상담사·점수·신뢰도·이슈)
• AI 개선 제안 롤링 바 및 조치 등록 모달 제공
• 컬럼별 정렬 (오름/내림/초기화) 지원
• 상세 분석 탭: 센터 > 팀 > 상담사 드릴다운 네비게이션"
자동 평가 현황	"■ 페이지 설명
AI가 자동으로 평가한 결과만 별도로 모아 보여주는 화면.
자동 평가의 신뢰도(High/Mid/Low)와 수동 검증 여부를 중심으로 관리하며,
신뢰도가 낮거나 아직 검증되지 않은 건을 빠르게 가려내
QA 매니저가 추가 확인할 대상을 식별하는 데 사용된다.

■ 주요 기능
• 검색 필터 제공 (센터·팀·기간·상담사·점수·평가표·신뢰도·이슈)
• 평가 현황 테이블에 신뢰도 색상 배지 표시
• 신뢰도 필터 제공 (High/Mid/Low)
• 수동 검증 상태 필터 (검증완료/미검증)
• 컬럼별 정렬 지원
• 행 클릭 시 평가 상세 정보 모달 표시"
수동 평가 현황	"■ 페이지 설명
QA 매니저(평가자)가 직접 진행하는 수동 평가의 진행 상태를 추적·관리하는 화면.
평가 계획에 따라 배정된 콜 중 어떤 건이 ‘미평가/평가완료’ 상태인지 확인하고,
행 클릭으로 바로 평가표를 열어 점수 입력 화면으로 진입할 수 있는
평가자의 작업 허브 역할을 한다.

■ 주요 기능
• 검색 필터 제공 (센터·팀·기간·상담사·평가자·통화유형·평가상태·점수)
• 평가 현황 테이블 (평가ID·일시·소속·상담사·평가자·평가상태·이슈)
• 평가 상태 필터 (미평가/평가완료)
• 평가자명 검색 기능
• 12개 컬럼별 정렬 (오름/내림/초기화) 지원
• 행 클릭 시 평가표 상세 및 점수 입력 화면 진입"
[관리자 - 평가 관리]	
평가 항목 관리	"■ 페이지 설명
평가표를 구성하는 ‘평가 항목(개별 질문)’을
대/중/소분류 3단계 계층 구조로 정의·관리하는 화면.
평가 체계의 토대가 되는 마스터 데이터로,
각 항목의 유형(정량/정성)·FAIL 여부·활성 상태·감점 규칙·참고 자료까지
한 곳에서 설정한다.
여기서 정의한 항목이 자동/수동 평가표에서 재사용된다.

■ 주요 기능
• 좌측 항목 트리뷰 (대/중/소분류 3단계 계층 구조)
• 항목별 유형 배지(정량/정성), FAIL 마크, 활성/비활성 상태 표시
• 우측 상세 패널 (선택 항목의 설정값·감점규칙·참고자료)
• 항목 추가/수정/삭제 모달 (인라인 편집 + 모달 모드)
• 카테고리·활성화 상태 기반 검색/필터
• 항목 총 수 표시"
자동 평가표 관리	"■ 페이지 설명
AI 자동 평가에 적용할 평가표를 정의하고 버전별로 관리하는 화면.
‘평가 항목 관리’에서 등록된 항목들을 조합해 평가표를 구성하고,
총점·미달기준·항목 구성·배점을 설정한다.
사용중/미사용 상태와 버전 이력을 통해
평가 기준이 시간에 따라 어떻게 변해왔는지 추적할 수 있다.

■ 주요 기능
• 검색 필터 (평가표명·유형·상태)
• 평가표 목록 테이블 (평가표명·유형·버전·총점·미달기준·항목수·상태·수정일)
• 상태 필터 (사용중/미사용)
• 새 평가표 생성 모달 (이름·유형·항목 선택·배점 설정)
• 행 클릭 시 평가표 상세 조회 (항목 구성·배점·미달기준)
• 평가표 복사/수정/삭제 액션 지원"
수동 평가표 관리	"■ 페이지 설명
사람 평가자가 직접 점수를 매길 때 사용하는 평가표를 정의·관리하는 화면.
자동 평가표와 구조는 유사하지만,
정성 평가 비중이 높은 항목 위주로 구성되며
평가자의 코멘트 입력 흐름을 고려해 설계된다.
평가표 단위로 버전 관리되어
‘이 시점의 평가는 어떤 기준이었나’를 소급 확인할 수 있다.

■ 주요 기능
• 검색 필터 (평가표명·유형·상태)
• 평가표 목록 테이블 (평가표명·유형·버전·총점·미달기준·항목수·상태·수정일)
• 상태 필터 (사용중/미사용)
• 새 평가표 생성 모달 (명칭·유형·항목 구성·배점 설정)
• 행 클릭 시 평가표 상세 조회 및 수정
• 평가표 복사/삭제 액션 지원"
이의 제기 처리함	"■ 페이지 설명
상담사가 본인의 평가 결과에 대해 제출한 이의를
관리자가 검토·승인·반려하는 처리 워크플로우 화면.
상태별(대기/검토중/처리완료) 건수를 요약 카드로 보여주고,
각 이의 건의 원점수와 요청 점수·사유를 확인한 뒤
의견을 남겨 점수 조정 여부를 결정한다.
처리 이력은 타임라인으로 남아 감사 추적이 가능하다.

■ 주요 기능
• 상태별 요약 카드 3종 (대기/검토중/처리완료 건수)
• 검색 필터 (기간·상태·센터·팀·상담사·이의항목·처리자)
• 이의 제기 목록 테이블 (제출일·평가ID·상담사·이의항목·원점수·요청점수·상태)
• 상태 배지 (대기/검토중/승인/반려)
• 행 클릭 시 이의 상세 및 처리 모달 (승인/반려/의견 입력)
• 처리 이력 및 타임라인 표시"
[관리자 - 평가 계획 관리]	
자동 평가 계획 관리	"■ 페이지 설명
AI 자동 평가를 ‘언제·어떤 평가표로·어떤 대상에·얼마나 자주’ 실행할지
정의하는 스케줄 관리 화면.
하나의 평가 계획에 평가표·기간·반복주기·대상 범위(센터·팀·상담사)를 묶어 등록하며,
계획별 활성화 토글로 즉시 켜고 끌 수 있어
운영 환경 변화에 유연하게 대응한다.

■ 주요 기능
• 검색 필터 (계획명·상태·반복주기·대상)
• 평가 계획 목록 테이블 (계획명·적용평가표·평가기간·반복주기·대상·상태)
• 상태 필터 (전체/진행중/예정/종료)
• 새 계획 추가 모달 (계획명·평가표 선택·기간·반복주기·대상 범위)
• 계획 수정/삭제/복사 액션 지원
• 계획 활성화/비활성화 토글 제공"
자동 평가 제외 관리	"■ 페이지 설명
자동 평가에서 의도적으로 제외해야 하는 대상·기간·조건을 정의하는 화면.
신규 입사자·휴직자처럼 평가에서 빼야 할 상담사,
교육·이벤트 기간처럼 평가가 부적절한 시점,
분석 가치가 낮은 짧은 통화 등을
4가지 탭(상담사/팀/기간/최소 통화시간) 기준으로 관리해
평가 노이즈를 줄인다.

■ 주요 기능
• 탭 기반 4종 제외 규칙 관리 (상담사 제외·팀 제외·기간 제외·최소 통화시간)
• 상담사 제외: 상담사·소속·사유·기간·활성화 항목 관리
• 팀 제외: 센터·팀·사유·기간·활성화 항목 관리
• 기간 제외: 기간·적용 범위·사유·활성화 항목 관리
• 통화시간 제외: 채널별 최소 시간(초) 설정
• 추가/수정/삭제 액션 (모달 기반) 지원"
수동 평가 계획 관리	"■ 페이지 설명
QA 매니저의 수동 평가 일정을 계획 단위로 관리하는 화면.
자동 평가 계획과 달리 ‘담당 평가자’가 명시적으로 배정되며,
계획별 평가 대상자 명단을 미리 확인할 수 있어
평가자 업무량 분배와 평가 진행률 관리에 활용된다.

■ 주요 기능
• 검색 필터 (계획명·상태·반복주기·대상·담당자)
• 평가 계획 목록 테이블 (계획명·적용평가표·평가기간·반복주기·대상·담당자·상태)
• 상태 필터 (전체/진행중/예정/종료)
• 새 계획 추가 모달 (계획명·평가표·기간·대상·담당자·반복 설정)
• 계획 수정/삭제/활성화 액션 지원
• 계획별 평가 대상자 목록 조회"
[관리자 - 분석]	
비교 분석	"■ 페이지 설명
센터 간 또는 팀 간의 품질 지표를 나란히 놓고 비교 분석하는 화면.
2~3개의 비교 대상을 선택하고
보고 싶은 위젯(품질점수추이·이슈발생률·점수분포·최다감점 등)을 토글해
사이드바이사이드로 펼쳐본다.
최고값 대비 격차와 추세 편차를 통해
‘어느 조직이 왜 잘하고/못하는지’ 인사이트를 도출한다.

■ 주요 기능
• 비교 유형 선택 제공 (센터 비교 / 팀 비교, 2~3개 대상)
• 위젯 토글 제어 (품질점수추이·평균QA점수·평가건수·이슈발생률·추세편차·상담시간·점수분포·최다감점 등)
• 사이드바이사이드 비교 카드 (대상별 KPI 병렬 표시)
• 최고값 대비 차이 표시 (▼ 상향/하향 아이콘)
• 차트 제공 (품질추이 라인·팀비교 바·이슈발생률 스택바)
• 위젯 클릭 시 통합 평가 현황으로 필터링 이동"
리포트 생성기	"■ 페이지 설명
일간·주간·월간·연간 단위의 품질 리포트를 자동 생성하는 화면.
포함할 섹션(개요·품질분석·팀상담사·이슈감점·종합)을 체크박스로 골라 구성하고,
미리보기 후 PDF로 내려받거나 이메일로 발송할 수 있다.
임원 보고·정기 회의 자료 준비 시간을 단축하며,
전기 개선 이행 현황도 함께 첨부 가능하다.

■ 주요 기능
• 리포트 유형 선택 (일간/주간/월간/연간/날짜 지정)
• 기간 입력 (날짜 지정 시 from~to 수동 입력)
• 포함 섹션 체크박스 (개요·품질분석·팀상담사·이슈감점·종합 5개 그룹)
• 요약(KPI 카드)·팀별 평가 현황(테이블)·점수 분포(도넛)·부록 섹션 구성
• 전기 개선 이행 현황 불러오기 모달 지원

개선 이행 관리	"■ 페이지 설명

FAIL 판정 규칙	"■ 페이지 설명

키워드 기반 규칙을 관리하는 화면.
좌측에는 절대 말해선 안 되는 ‘금지어’,
우측에는 반드시 말해야 하는 ‘필수 고지사항’을 나누어 관리한다.
각 키워드는 적용 상담유형(I/B·O/B)별로 활성/비활성을 토글할 수 있어
규정 변경에 빠르게 대응할 수 있다.

■ 주요 기능
• 좌우 2컬럼 레이아웃 (금지어 / 필수 고지사항)
• 금지어 테이블 (No·키워드·설명·상담유형·상태·관리)
• 필수 고지 테이블 (No·키워드·설명·상담유형·상태·관리)
• 추가/수정 모달 (키워드 + 적용 상담유형 1행 배치, 설명 다음 행)
• 상태 토글 스위치 (활성/비활성 전환)
• 상담유형 드롭다운 (전체/I/B/O/B)"

## 사용법

1. 위 `구분	내용` 행부터 마지막 행(`나의 이의 제기 현황 ...`)까지 그대로 복사
2. 엑셀의 A1 셀에 그대로 붙여넣기
3. 자동으로 2개 컬럼(구분/내용)으로 분리되며, 내용 셀은 큰따옴표가 제거되고 셀 내 줄바꿈(Alt+Enter)으로 변환됨
4. 카테고리 헤더 행(`[관리자 - 홈]` 등)은 그룹 구분용. 필요 시 굵게/배경색 처리하거나 삭제
5. 셀 너비 자동 맞춤 + 자동 줄바꿈(Wrap Text) 옵션 켜면 첨부 이미지와 동일한 모양
