## 3. Key UI Components

### 3.0 UI 패턴 가이드 (전문가용 인터페이스)

**기본 원칙: 데이터 밀도 중심, 효율적 탐색**

#### **리스트 + 모달 패턴 (표준)**

```
[리스트 뷰]
- 테이블 형식으로 다량의 데이터 표시
- 정렬, 필터, 검색 기능 제공
- 한 줄에 핵심 정보 요약
- 행 전체가 클릭 가능 (클릭 시 상세 모달)
  • 호버 시: 배경색 변경 (예: #f5f5f5)
  • 커서: pointer
  • 시각적 피드백으로 클릭 가능 암시
- 특정 액션 버튼만 별도 배치
  • 이의 제기, 삭제 등 주요 액션
  • 버튼 클릭 시 이벤트 버블링 중단 (행 클릭 방지)

[모달 팝업 - 행 클릭 시]
- 중앙 팝업 (백드롭으로 배경 어둡게)
- 상세 정보 + 탭 구조
- ESC 또는 백드롭 클릭으로 빠른 닫기
- 닫기 후 리스트로 복귀 (스크롤 위치 유지)
```

**[×] 지양할 패턴**
- 카드 형식 남발 (공간 낭비)
- 페이지 전환 과다
- 장식적 요소 과다

**✅ 권장 패턴**
- 테이블/리스트 기본
- **행 전체 클릭 가능** (호버 시 배경색 변경, 커서 포인터)
- 모달 팝업으로 상세 표시
- 특정 액션 버튼만 별도 배치 (이의 제기 등)
- 탭으로 정보 분류

### 3.1 XAI(설명 가능한 AI) 위젯

**점수 설명 툴팁**
- 점수 옆 'Why?' 아이콘/툴팁 배치
- 마우스 오버 시 자연어로 이유 설명
- 가점/감점 요인 분리 표시
- 해당 구간 재생 버튼 연동

**스크립트 하이라이트 시각화**
- 긍정 하이라이트: 초록색 배경 (공감 표현 등)
- 부정 하이라이트: 빨간색 배경 (말 끊기, 금지어)
- 규정 준수 하이라이트: 파란색 배경 (NLP 검증)
- 각 하이라이트에 판단 근거 툴팁

### 3.2 하이브리드 엔진 시각화

**NLP vs AI 분리 표시**
```
┌─────────────────────────────┬─────────────────────────────┐
│ [NLP] Engine (규정/절차)    │ [AI] Engine (소프트스킬)   │
├─────────────────────────────┼─────────────────────────────┤
│ ✓ 녹취 안내         +10    │ ✓ 공감 표현         +15    │
│ ✓ 상담사명 고지      +5    │ ✓ 감정 전환 성공     +10    │
│ ✓ 본인확인 절차     +10    │ ✗ 사전 공감 부족     -10    │
│ ✗ 추가문의 확인      -5    │ △ 응대 속도          -8    │
├─────────────────────────────┼─────────────────────────────┤
│ NLP 기여도: 30점            │ AI 기여도: 15점            │
│ 정확도: 100% ✓              │ 신뢰도: 92% (High)          │
└─────────────────────────────┴─────────────────────────────┘
```

**Cross-Validation 표시**
- AI 판단에 대한 NLP 상호 검증 결과
- 일치/불일치 여부 및 신뢰도 조정 내역

**AI 프롬프트 관리 핵심 기능:**

1. **평가 기준 작성** (System Prompt)
   - 자연어로 평가 기준 상세 작성
   - 점수 산정 가이드 명시
   - 근거 제시 요구 포함

2. **톤 앤 매너 설정**
   - 엄격/표준/관대 중 선택
   - 평가 난이도 조정

3. **프롬프트 테스트**
   - 실제 상담 데이터로 테스트
   - 결과 미리보기
   - 개선 제안 제공

4. **템플릿 라이브러리**
   - 자주 쓰는 프롬프트 저장/재사용
   - 시나리오별 템플릿 제공

   - AI 프롬프트 (AI 방식인 경우)
   - 사용 중인 평가표 추적

   - 한 번 만든 항목을 여러 평가표에서 사용
   - 항목 수정 시 모든 평가표에 자동 반영

**1단 메인 메뉴 (고정):**
- 너비: 176px (w-44)
- 배경: 틸 그린 (#0F766E)
- 항상 화면에 고정
- 메인 컨텐츠는 1단 너비만큼만 마진

```
AICC 플랫폼
├─ 에이전트 빌더
├─ 상담 어드바이저
├─ AICM
├─ TA
└─ QA ◀ 마우스 오버 시 2단 열림
```

**2단 서브메뉴 (오버레이):**
- 너비: 320px (w-80)
- 배경: 흰색
- **마우스 오버 시에만 표시** (기본 숨김)
- 그림자: `box-shadow: 8px 0 30px rgba(0,0,0,0.15)`
- 메인 컨텐츠 위에 떠 있는 오버레이 형태

```
QA
├─ 홈
│   ├─ QA 대시보드
│   └─ 평가 현황
├─ 평가 관리
│   ├─ 평가 항목 관리
│   └─ 평가표 관리
├─ 분석
│   ├─ 상세 분석
│   ├─ 트렌드 분석
│   └─ 리포트 생성기
├─ 이의 제기 처리함
├─ 시스템 설정
├─ ━━━━━━━━━━━━━━━
├─ 나의 성과 대시보드
├─ 나의 평가 결과
├─ 나의 이의 제기 현황
└─ 코칭 관리 (추후)
```

**마우스 오버 동작:**
1. 1단 메뉴의 "QA" 항목에 마우스 오버 → 2단 서브메뉴 표시
2. 서브메뉴 안에 마우스가 있으면 계속 표시 유지
3. 서브메뉴에서 마우스가 벗어나면 150ms 후 숨김
4. 메인 컨텐츠 영역에 영향 없음 (오버레이로 떠 있음)

### 6.1 기존 플랫폼 화면 분석

**참고 이미지 1: AICC 플랫폼 메인 화면**

**주요 특징:**
- ○ 왼쪽 사이드 메뉴 (약 200px, 고정 위치)
- ○ ELP 로고 상단 배치
- ○ 메뉴 검색 기능
- ○ 계층적 메뉴 구조 (AICC 플랫폼 > QA)
- ○ 틸 그린 계열 브랜드 컬러 (`#0F766E`)
- ○ 활성 메뉴 녹색 배경 처리
- ○ 메뉴 아이콘 + 텍스트 조합

**적용 방법:**
```
QA 메뉴는 "AICC 플랫폼" 하위에 추가
→ 클릭 시 서브메뉴 펼침/접힘
→ QA 홈, 평가 관리, 분석, 이의 제기, 설정
```

**참고 이미지 2: 리스트 형식 화면 (평가 항목 관리)**

**주요 특징:**
- ○ 상단 탭 네비게이션 (대시보드, 평가 항목 관리 등)
- ○ 검색 조건 섹션 (접기/펴기 가능)
- ○ 테이블 리스트 형식
  - 체크박스 (일괄 작업용)
  - 상태 배지 (수동, CHAT, CALL 등)
  - 평가 방식 배지 (AI: 주황색, NLP: 파란색)
  - 가감점 수치 표시
  - 상태 (사용/미사용)
- ○ 하단 페이지네이션
  - 이전/다음 버튼
  - 페이지 번호
  - 페이지당 건수 선택 (30건, 50건 등)
- ○ 우측 상단 액션 버튼 (검색, 저장 등)

**적용 방법:**
```
모든 리스트 화면에 이 디자인 패턴 적용:
- 평가 항목 관리
- 평가표 관리
- 평가 결과 상세
- 이의 제기 처리함
- 프롬프트 템플릿 라이브러리
```
