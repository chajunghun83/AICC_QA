### 5.2 개발 순서 가이드

**Phase 1: 기본 레이아웃 및 메뉴 (우선순위: 최고)**
1. ✅ 상단 헤더 + 왼쪽 사이드 메뉴 (2단 오버레이 구조)
2. ✅ 메뉴 네비게이션 (링크 연결)
3. ✅ 권한별 메뉴 표시/숨김 시뮬레이션
4. ✅ 기본 색상 및 타이포그래피 적용

**Phase 2: 홈 (QA 대시보드, 평가 현황)**
1. ✅ QA 대시보드
   - 4개 핵심 지표 카드
   - 품질 추세 그래프
   - 팀/채널 비중 파이 차트
   - 이슈 알림 카드
   - 평가 현황 간소 테이블
   - 개선 필요 항목 Top5
2. ✅ 평가 현황 상세
   - 센터-팀 필터
   - 평가 결과 리스트 테이블
   - 행 클릭 → 평가 상세 모달

**Phase 3: 평가 관리**
1. ✅ 평가 항목 관리
   - 트리 구조 (카테고리-항목)
   - 항목 상세 패널
   - 카테고리/항목 추가/편집 모달
   - AI 프롬프트 편집 (템플릿 라이브러리 연동)
2. ✅ 평가표 관리
   - 평가표 리스트
   - 평가표 편집 (항목 라이브러리에서 추가)
   - 항목별 배점 조정

**Phase 4: 분석**
1. ✅ 상세 분석
   - 센터 → 팀 → 개인 → 상담 건 드릴다운
   - 각 레벨별 테이블 뷰
2. ✅ 트렌드 분석
   - 기간별 추세 그래프
   - 팀별/항목별 비교
3. ✅ 리포트 생성기
   - 리포트 설정 폼
   - 템플릿 미리보기

**Phase 5: 이의 제기 처리함**
1. ✅ 이의 제기 리스트 (관리자)
   - 상태별 필터 (대기/처리완료)
   - 행 클릭 → 이의 제기 상세 모달
2. ✅ 이의 제기 모달
   - 원 평가 결과 + 이의 사유
   - 관리자 처리 (승인/반려)

**Phase 6: 시스템 설정**
1. ✅ 평가 계획 관리
   - 평가 계획 리스트
   - 평가 계획 상세 모달 (기간/대상/비율/스케줄)
2. ✅ 프롬프트 템플릿 라이브러리
   - 템플릿 리스트
   - 템플릿 상세 모달 (프롬프트/사용통계/버전히스토리)
3. ✅ 사용자 관리
   - 사용자 리스트
   - 역할 배정
4. ✅ 시스템 로그
   - 로그 테이블 (사용자/활동/시간)

**Phase 7: 상담사 My Zone**
1. ✅ 나의 성과 대시보드
   - 본인 평균 점수
   - 추세 그래프
   - 최근 평가 내역
2. ✅ 나의 평가 결과
   - 본인 평가 리스트
   - 행 클릭 → 평가 상세 모달
3. ✅ 나의 이의 제기 현황
   - 제출한 이의 제기 목록
   - 이의 제기 제출 폼

**Phase 8: 최종 검수 및 완성도 향상**
1. ✅ 모든 화면 간 링크 점검
2. ✅ 호버 효과, 애니메이션 최적화
3. ✅ 반응형 디자인 검토 (선택 사항)
4. ✅ 더미 데이터 충실도 검토
5. ✅ README 작성

### 5.4 기술 스택

| 영역 | 권장 기술 | 용도 |
|------|----------|------|
| Frontend | HTML5 + Tailwind CSS + Alpine.js | 화면 구성 및 간단한 인터랙션 |
| 더미 데이터 | JSON 파일 | 정적 데이터로 화면 동작 시연 |
| 차트 | Chart.js | 그래프 시각화 (기존 플랫폼과 동일) |
| 아이콘 | Heroicons, Lucide | UI 아이콘 |
| 폰트 | Pretendard (한글), JetBrains Mono (코드) | 타이포그래피 |

**프로토타입 특성:**
- 📁 더미 데이터는 `/assets/dummy-data/` 폴더에 JSON 형식으로 관리
- 🔄 실시간 연동은 JavaScript setInterval로 시뮬레이션
- 🎭 모든 인터랙션은 클라이언트 사이드에서 처리
- 🚫 백엔드 API, 데이터베이스 불필요

  if (currentUser.role === 'AGENT') {
    // 상담사는 관리자 메뉴 숨김
    adminMenus.forEach(menu => menu.style.display = 'none');
  } else {

    // (기본값이므로 처리 불필요)
  }

// 센터-팀 계층 필터링 시뮬레이션
let centers = []; // centers.json에서 로드

function onCenterChange(centerId) {
  const teamSelect = document.getElementById('team-select');

  if (centerId === 'all') {
    // 전체 선택 시 팀 필터 비활성화
    teamSelect.disabled = true;
    teamSelect.value = 'all';
  } else {
    // 특정 센터 선택 시 해당 센터의 팀만 표시
    const center = centers.find(ws => ws.id === centerId);
    teamSelect.disabled = false;

    // 팀 옵션 동적 생성
    teamSelect.innerHTML = '<option value="all">전체</option>';
    center.teams.forEach(team => {
      teamSelect.innerHTML += `<option value="${team.id}">${team.name}</option>`;
    });
  }

  // 데이터 다시 로드
  loadDashboardData(centerId, teamSelect.value);
}
