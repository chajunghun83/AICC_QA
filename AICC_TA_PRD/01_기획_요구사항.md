## 0. 프로젝트 배경 및 목적

### 0.1 현재 상황

**보유 인프라:**
- ✅ AICC 플랫폼 운영 중
- ✅ 어드바이저(상담사) 통화 자동 STT 변환 및 저장 기능 완료
- ✅ STT 데이터 축적 중
- ✅ QA 모듈 프로토타입 완성 (디자인/컴포넌트 레퍼런스 활용 가능)

**TA 영역 현황:**
- ✅ TA 페이지 10개 기존 소스 존재 (메뉴 구조/기능 정리 필요)
- ❌ 기존 메뉴 구조가 실제 운영 시나리오와 불일치
- ❌ 불필요한 관리 메뉴 포함 (요약문구 관리, 권한 관리 등)

### 0.2 프로젝트 목적

**본 프로젝트의 목표:**
> **"STT 데이터 기반 키워드/상담 분석 시스템의 화면 프로토타입 재정비"**

**명확한 범위 정의:**

| 구분 | 내용 |
|------|------|
| **목적** | 고객 통화에서 발생하는 키워드를 분석하고 결과를 시각화하여 기획 검증 |
| **산출물** | 기능하는 화면 프로토타입 (UI/UX 중심) |
| **기반** | QA 모듈의 디자인 시스템·컴포넌트 테마 재활용 |
| **데이터** | 더미 데이터 사용 (실제 API 연동 불필요) |
| **접근 방식** | 기존 TA 소스를 기반으로 메뉴 구조 정리 및 화면 개선 |

**프로토타입 요구사항:**
```
✅ 해야 할 것:
- QA와 동일한 디자인 시스템/컴포넌트 활용
- 메뉴 구조 재정비 (10개 → 8개)
- 더미 데이터로 동작 시연
- 키워드 분석 결과 시각화
- 드릴다운 (대시보드 → 상세 → 콜 건)

❌ 하지 않아도 되는 것:
- 실제 STT 연동
- 키워드 추출 엔진 구현
- 백엔드 API 개발
- 데이터베이스 구축
```

### 0.3 TA와 QA의 관계

```
[AICC 플랫폼]
      ↓
어드바이저 통화
      ↓
STT 자동 변환 ✅ (기존 기능)
      ↓
텍스트 데이터 저장 ✅ (기존 기능)
      ↓
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
      ↓                         ↓
[QA 모듈]                   [TA 모듈]
품질 평가 (점수/감점)        키워드·상담 분석
평가 항목별 채점             트렌드·이슈 탐지
이의 제기 관리               상담 유형 분류
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**핵심 차이:**

| 구분 | QA (Quality Assurance) | TA (Text Analytics) |
|------|----------------------|---------------------|
| **목적** | 상담 품질 평가·점수화 | 상담 내용 분석·인사이트 도출 |
| **분석 단위** | 평가 항목 (인사, 공감, 해결력 등) | 키워드 (빈도, 추이, 연관) |
| **결과물** | 평가 점수, 감점 사유, 코칭 | 키워드 트렌드, 이슈 탐지, 상담 유형 |
| **사용자 액션** | 평가표 관리, 이의 제기 | 키워드 등록, 분석 기준 설정 |

### 0.4 프로젝트 성공 기준

| 항목 | 기준 |
|------|------|
| **화면 완성도** | 8개 메뉴 화면 구현 (더미 데이터) |
| **디자인 일관성** | QA 모듈과 동일한 디자인 시스템·테마 적용 |
| **인터랙션** | 드릴다운, 필터, 탭 전환, 모달 동작 |
| **이해도** | 이해관계자가 "키워드 분석이 이렇게 동작하는구나" 이해 |

## 1. Project Vision

### 1.1 핵심 목표

**"고객 통화 속 숨겨진 인사이트를 키워드 분석으로 실시간 가시화"**

고객 상담 통화의 STT 데이터에서 키워드를 추출·분석하여, 급상승 이슈 탐지, 상담 유형 분류, 콜 품질 모니터링을 제공하는 **텍스트 분석 플랫폼**

### 1.2 핵심 가치 제안

| 문제점 | 솔루션 |
|--------|--------|
| 수천 건 통화 내용을 수동 확인 불가 | 키워드 자동 추출 및 빈도·추이 분석 |
| 이슈 발생 시 인지 시차 | 급상승 키워드 실시간 탐지 + 알림 |
| 상담 유형 분류가 수동 | STT 기반 자동 상담 유형 분류 |
| 묵음·재인입 등 콜 품질 파악 어려움 | 묵음 시간, 재인입, 초과 콜 자동 감지 |

### 1.3 분석 체계

```
┌─────────────────────────────────────────────────────────────┐
│                    STT 텍스트 데이터 수집                       │
└─────────────────────────┬───────────────────────────────────┘
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│ 키워드 분석      │ │ 상담 유형 분류   │ │ 콜 품질 분석     │
│ ───────────────│ │ ───────────────│ │ ───────────────│
│ • 급상승 키워드  │ │ • 대/중/소 분류  │ │ • 묵음 구간 감지 │
│ • 고빈도 키워드  │ │ • 유형별 통계    │ │ • 재인입 콜 추적 │
│ • 모니터링 키워드│ │ • 히트맵 시각화  │ │ • 초과 콜 감지   │
│ • 위험 키워드    │ │ • 추이 분석      │ │ • 이슈 콜 관리   │
│ • 이슈 키워드    │ │                 │ │                 │
└─────────────────┘ └─────────────────┘ └─────────────────┘
          │               │               │
          └───────────────┼───────────────┘
                          ▼
              ┌───────────────────────┐
              │ TA 대시보드 통합 시각화  │
              └───────────────────────┘
```

**키워드 유형 분류:**

| 유형 | 설명 | 용도 |
|------|------|------|
| **급상승 키워드** | 최근 기간 대비 빈도 급증 | 이슈 조기 탐지 |
| **고빈도 키워드** | 전체 기간 기준 가장 많이 언급 | 상시 모니터링 |
| **모니터링 키워드** | 관리자가 직접 등록하여 추적 | 특정 이슈 추적 |
| **위험 키워드** | 컴플레인·불만·해지 등 | 리스크 조기 경보 |
| **이슈 키워드** | 규칙 기반 자동 이슈 판정 | 이슈 콜 자동 분류 |
| **제외 키워드** | 분석에서 제외할 불용어 | 노이즈 필터링 |

## 3. 화면별 상세 구성

### 3.1 TA 홈 (대시보드)

**파일:** `pages/ta/ta-dashboard.html`
**목적:** TA 전체 현황을 한 화면에서 파악

| 영역 | 위젯 | 설명 |
|------|------|------|
| 상단 KPI | 카드 4개 | 전체 콜, 이슈 콜, 초과 콜, 재인입 콜 (건수 + 전기 대비 증감) |
| 좌측 상단 | 급상승 키워드 Top 5 | 테이블 (키워드, 빈도, 증감률) |
| 좌측 중간 | 위험 키워드 | 배지 형태 (빨간색 강조) |
| 우측 상단 | 상담 유형 히트맵 | 유형 × 시간대 격자, 색상 농도로 건수 표현 |
| 하단 좌측 | 시간대별 콜 분포 | 막대 차트 (24시간 분포) |
| 하단 우측 | 고빈도 키워드 워드클라우드 | 텍스트 크기로 빈도 표현 |

**드릴다운 흐름:**
```
[대시보드 위젯] → [키워드 상세 모달] → [관련 콜 리스트] → [콜 상세 모달]
```

### 3.2 콜 상담

**파일:** `pages/ta/call-consultation.html`
**목적:** 전체 콜 현황 분석 및 상세 조회

| 영역 | 구성 | 설명 |
|------|------|------|
| 필터 | 기간 선택, 검색 | 기간 + 키워드 검색 |
| 탭 | 전체 콜 / 재인입 / 묵음 / 이슈 | 4개 탭으로 콜 분류 |
