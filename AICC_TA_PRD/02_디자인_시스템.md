## 1. 디자인 원칙

### 1.1 기본 원칙: 데이터 밀도 중심, 효율적 탐색

엔터프라이즈급 B2B 소프트웨어로서 전문가가 빠르게 데이터를 탐색하고 의사결정할 수 있도록 설계한다.

**권장 패턴:**
- 테이블/리스트 기본
- **행 전체 클릭 가능** (호버 시 배경색 변경 `#F5F5F5`, 커서 포인터)
- 모달 팝업으로 상세 표시
- 특정 액션 버튼만 별도 배치 (이의 제기, 삭제 등)
- 탭으로 정보 분류

**지양 패턴:**
- 카드 형식 남발 (공간 낭비)
- 페이지 전환 과다
- 장식적 요소 과다

### 1.2 리스트 + 모달 패턴 (표준)

```
[리스트 뷰]
- 테이블 형식으로 다량의 데이터 표시
- 정렬, 필터, 검색 기능 제공
- 행 전체가 클릭 가능 (호버 시 #F5F5F5, 커서 pointer)
- 특정 액션 버튼만 별도 배치 (이벤트 버블링 중단)

[모달 팝업 - 행 클릭 시]
- 중앙 팝업 (백드롭으로 배경 어둡게)
- 상세 정보 + 탭 구조
- ESC 또는 백드롭 클릭으로 닫기
- 닫기 후 리스트로 복귀 (스크롤 위치 유지)
```

### 1.3 아이콘/이모티콘 가이드라인

**"AI가 만든 티가 나는 디자인" 지양**

| 구분 | 허용 | 금지 |
|------|------|------|
| **점수 상태** | `●` (원형 도트, CSS 색상) | 컬러 이모지 |
| **메뉴 아이콘** | SVG 아이콘 또는 최소한의 텍스트 | 장식용 이모지 |
| **이슈/알림** | 텍스트 또는 배지 | 감정/상태 이모지 |
| **버튼/액션** | 텍스트 또는 SVG 아이콘 | 이모지 사용 금지 |

## 4. 레이아웃

### 4.1 전체 구조

```
┌────────────────────────────────────────────────────────────┐
│ [1단 사이드바]  [헤더 탭 바 (40px)]                          │
│ (176px, 고정)  ┌─────────────────────────────────────────┐ │
│                │ 메인 콘텐츠 영역                          │ │
│                │ (margin-left: 176px, 스크롤 가능)         │ │
│                │                                         │ │
│                │ padding: 24px                            │ │
│                └─────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

### 4.2 사이드 메뉴 (2단 오버레이 방식)

```
┌─────────┬──────────────┬─────────────────────────────────────────┐
│ 1단     │ 2단          │ 메인 콘텐츠                             │
│ 메인    │ 서브메뉴     │                                         │
│ (고정)  │ (오버레이)   │ (1단 메뉴 너비만큼만 마진)              │
│         │              │                                         │
│ w-44    │ w-80         │ ml-44                                   │
│ (176px) │ (320px)      │                                         │
└─────────┴──────────────┴─────────────────────────────────────────┘
```

**1단 메인 메뉴 (고정):**
- 너비: 176px
- 배경: `#00A3FF`
- 항상 화면에 고정 (`position: fixed`)
- z-index: 50

**2단 서브메뉴 (오버레이):**
- 너비: 320px
- 배경: 흰색
- 마우스 오버 시에만 표시 (기본 숨김)
- `box-shadow: 8px 0 30px rgba(0,0,0,0.15)`
- 표시/숨김: `transform + opacity` 트랜지션 (200ms)
- 숨김 지연: 150ms (1단↔2단 이동 시 깜빡임 방지)

**마우스 오버 동작:**
1. 1단 메뉴의 "QA" 또는 "TA" 항목에 마우스 오버 -> 해당 모듈의 2단 서브메뉴 표시
2. 서브메뉴 안에 마우스가 있으면 계속 표시 유지
3. 서브메뉴에서 마우스가 벗어나면 150ms 후 숨김
4. 메인 콘텐츠 영역에 영향 없음 (오버레이로 떠 있음)

### 4.3 헤더 탭 바

- 높이: 40px
- 배경: `#F5F5F5`
- 하단 border: `1px solid #E0E0E0`
- `position: sticky; top: 0; z-index: 30`
- 탭 가로 스크롤 지원 (스크롤바 숨김)
- 3점 메뉴 (다른 탭 닫기, 모든 탭 닫기, 대시보드로 이동)

### 4.4 QA 메뉴 구조 (sidebar.js 기준)

```
QA (관리자 영역)
├── 홈
│   ├── QA 대시보드
│   ├── 통합 평가 현황
│   ├── 자동 평가 현황
│   └── 수동 평가 현황
├── 평가 관리
│   ├── 평가 항목 관리
│   ├── 자동 평가표 관리
│   ├── 수동 평가표 관리
│   └── 이의 제기 처리함
├── 평가계획관리
│   ├── 자동 평가 계획 관리
│   ├── 자동 평가 제외 관리
│   └── 수동 평가 계획 관리
├── 분석
│   ├── 비교 분석
│   └── 리포트 생성기
├── 시스템 설정
│   ├── 프롬프트 템플릿

────────────────────
MY ZONE (상담사 영역)
├── 나의 성과 대시보드
├── 나의 평가 결과

```

## 6. JS 컴포넌트 API

모든 컴포넌트는 `window.AICC_*` 전역 객체로 제공된다.

### 6.1 AICC_Sidebar (`js/components/sidebar.js`)

사이드바 메뉴 렌더링 및 호버 이벤트 관리.

| 메서드 | 파라미터 | 반환 | 설명 |
|--------|---------|------|------|
| `init(basePath)` | `basePath: string` | - | 상대 경로 설정 |
| `getActiveId()` | - | `string` | 현재 페이지 파일명 (`.html` 제외) |
| `render1stTier(module)` | `module: 'qa' \| 'ta'` | HTML string | 1단 사이드바 HTML 생성 |
| `render2ndTier(module)` | `module: 'qa' \| 'ta'` | HTML string | 2단 서브메뉴 HTML 생성 |
| `bindEvents()` | - | - | QA/TA 호버 이벤트 바인딩 |

**메뉴 데이터:** `menuItems.admin`, `menuItems.agent`, `menuItems.ta`

### 6.2 AICC_Layout (`js/components/layout.js`)

페이지 공통 레이아웃 (사이드바 + 헤더 탭) 주입.

| 메서드 | 파라미터 | 반환 | 설명 |
|--------|---------|------|------|
| `getBasePath()` | - | `string` | 페이지 깊이별 상대 경로 (`../../` 등) |
| `getTabs()` | - | `Tab[]` | sessionStorage 탭 목록 |
| `saveTabs(tabs)` | `tabs: Tab[]` | - | 탭 목록 저장 |
| `getCurrentPageInfo()` | - | `{id, label, href}` | 현재 페이지 정보 |
| `addCurrentTab()` | - | - | 현재 페이지를 탭에 추가 |
| `removeTab(tabId)` | `tabId: string` | - | 탭 제거 |
| `closeOtherTabs()` | - | - | 다른 탭 닫기 |
| `closeAllTabs()` | - | - | 모든 탭 닫기 |
| `navigateToDefault()` | - | - | QA 대시보드로 이동 |
| `init()` | - | - | 레이아웃 초기화 (자동 호출) |

**경로 매핑:**
- `pages/admin/system-settings/` -> `../../../`
- `pages/ta/system/` -> `../../../`
- `pages/admin/`, `pages/agent/`, `pages/ta/` -> `../../`

### 6.3 AICC_Modal (`js/components/modal.js`)

범용 모달 팝업 (싱글턴).

| 메서드 | 파라미터 | 설명 |
|--------|---------|------|
| `open(options)` | `{title, content, footer, size, onClose}` | 모달 열기 |
| `close()` | - | 모달 닫기 (200ms 애니메이션) |
| `confirm(message, onConfirm)` | `message: string, onConfirm: Function` | 확인/취소 다이얼로그 |

**options.size:**

| 값 | 최대 너비 |
|-----|----------|
| `sm` | 480px |
| `md` | 640px |
| `lg` | 800px (기본값) |
| `xl` | 1000px |
| `xxl` | 1300px |
| `full` | 90% |

**동작:** ESC 키, 백드롭 클릭으로 닫기. 동시 1개만 표시.

### 6.4 AICC_Toast (`js/components/toast.js`)

하단 우측 토스트 알림 (싱글턴).

| 메서드 | 파라미터 | 설명 |
|--------|---------|------|
| `show(message, duration)` | `message: string, duration: number (기본 3000)` | 토스트 표시 |

기존 토스트 제거 후 표시. `duration`ms 후 fade-out (300ms) 후 DOM 제거.

### 6.5 AICC_PeriodPicker (`js/components/period-picker.js`)

기간 선택기 (2패널 레이아웃).

| 메서드 | 파라미터 | 반환 | 설명 |
|--------|---------|------|------|
| `create(containerId, opts)` | `containerId: string, opts: object` | `{state, refresh}` | 인스턴스 생성 |

**opts:**

| 옵션 | 타입 | 설명 |
|------|------|------|
| `defaultPeriod` | `'daily' \| 'weekly' \| 'monthly' \| 'yearly' \| 'custom'` | 초기 모드 |
| `defaultDate` | `Date \| string` | 초기 날짜 |
| `onChange(periodType, dateInfo)` | `Function` | 선택 변경 콜백 |

**dateInfo 구조 (periodType별):**
- `daily`: `{ type, date }`
- `weekly`: `{ type, from, to }`
- `monthly`: `{ type, year, month }`
- `yearly`: `{ type, year }`
- `custom`: `{ type, from, to }`

### 6.6 AICC_Fmt (`js/utils/formatters.js`)

숫자, 날짜, 점수 포맷팅 유틸리티. `null`/`undefined` 입력 시 `'-'` 반환.

| 메서드 | 파라미터 | 반환 | 예시 |
|--------|---------|------|------|
| `number(n)` | `number` | `string` | `1234` -> `"1,234"` |
| `percent(n, decimals)` | `number, number(기본 1)` | `string` | `85.678` -> `"85.7%"` |
| `score(n)` | `number` | `string` | `82` -> `"82.0"` |
| `scoreStatus(score)` | `number` | `'good' \| 'warn' \| 'danger'` | 80+ good, 60+ warn |
| `scoreHtml(score)` | `number` | HTML string | 도트 + 색상 숫자 |
| `scoreColor(score)` | `number` | `string` | `#4CAF50` / `#FFC107` / `#F44336` |
| `date(dateStr)` | `string` | `string` | `"2024-01-15"` -> `"2024.01.15"` |
| `time(timeStr)` | `string` | `string` | `"14:30"` -> `"14:30"` |
| `datetime(dateStr)` | `string` | `string` | `"2024.01.15 14:30"` |
| `duration(str)` | `string` | `string` | 통화시간 mm:ss |
| `typeBadge(type)` | `'AI' \| 'NLP' \| 'Manual'` | HTML string | 색상 배지 HTML |
| `statusBadge(status, text)` | `string, string` | HTML string | 상태 배지 HTML |
| `trend(current, previous)` | `number, number` | HTML string | `▲ 3.2` (녹색) / `▼ 1.5` (빨간) |

### 6.7 AICC_Auth (`js/utils/auth-simulator.js`)

프로토타입용 역할 전환 시뮬레이터.

| 메서드 | 파라미터 | 반환 | 설명 |
|--------|---------|------|------|
| `getRole()` | - | `'ADMIN' \| 'AGENT'` | 현재 역할 (localStorage) |
| `setRole(role)` | `role: string` | - | 역할 저장 |
| `getCurrentUser()` | - | `{role, label, name, team, center}` | 현재 사용자 정보 |
| `isAdmin()` | - | `boolean` | 관리자 여부 |
| `switchRole(role)` | `role: string` | - | 역할 전환 + 리다이렉트 |
| `renderRoleToggle()` | - | - | 좌하단 역할 전환 UI 렌더 |

**프로필:**
- ADMIN: 김관리자, QA팀, 전체
- AGENT: 홍길동, VIP상담팀, 서울센터

### 6.8 AICC_DataLoader (`js/utils/data-loader.js`)

JSON 더미 데이터 로드 (캐시 -> 인라인 -> fetch 순 폴백).

| 메서드 | 파라미터 | 반환 | 설명 |
|--------|---------|------|------|
| `init()` | - | - | basePath 설정 (자동 호출) |
| `load(filename)` | `filename: string` | `Promise<any>` | JSON 파일 로드 |
| `loadAll(filenames)` | `filenames: string[]` | `Promise<Object>` | 여러 파일 병렬 로드 |

**로드 순서:**
1. 메모리 캐시 확인
2. `window.AICC_DATA[filename]` 인라인 데이터 확인 (`all-data.js`)
3. `fetch()` 로 `assets/dummy-data/{filename}` 로드

`file://` 프로토콜에서는 fetch 실패하므로 `all-data.js`의 인라인 데이터를 우선 사용.

## 8. 화면 와이어프레임

### 8.1 XAI(설명 가능한 AI) 위젯

**점수 설명 툴팁:**
- 점수 옆 'Why?' 아이콘/툴팁 배치
- 마우스 오버 시 자연어로 이유 설명
- 가점/감점 요인 분리 표시
- 해당 구간 재생 버튼 연동

**스크립트 하이라이트 시각화:**
- 긍정 하이라이트: 초록색 배경 (공감 표현 등)
- 부정 하이라이트: 빨간색 배경 (말 끊기, 금지어)
- 규정 준수 하이라이트: 파란색 배경 (NLP 검증)

### 8.2 하이브리드 엔진 시각화

```
┌─────────────────────────────┬─────────────────────────────┐
│ [NLP] Engine (규정/절차)    │ [AI] Engine (소프트스킬)     │
├─────────────────────────────┼─────────────────────────────┤
│ ✓ 녹취 안내         +10    │ ✓ 공감 표현         +15    │
│ ✓ 상담사명 고지      +5    │ ✓ 감정 전환 성공     +10    │
│ ✓ 본인확인 절차     +10    │ ✗ 사전 공감 부족     -10    │
│ ✗ 추가문의 확인      -5    │ △ 응대 속도          -8    │
├─────────────────────────────┼─────────────────────────────┤
│ NLP 기여도: 30점            │ AI 기여도: 15점             │
│ 정확도: 100%                │ 신뢰도: 92% (High)          │
└─────────────────────────────┴─────────────────────────────┘
```
