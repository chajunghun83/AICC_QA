# TA 파일 트리 구조

```
pages/ta/
├── ta-dashboard.html          # TA 홈
├── call-status.html           # 전체 콜 현황
├── call-consultation.html     # 콜 상담
├── consultation-type.html     # 상담 유형
├── issue-manage.html          # 이슈 처리 관리
├── report-generator.html      # 리포트 생성기
└── system/
    ├── keyword-manage.html    # 키워드 관리
    ├── analysis-settings.html # 분석 기준 관리
    └── logs.html              # 시스템 로그
```

## 사이드바 메뉴 구조

```
TA
├── 홈
│   ├── TA 홈                    → ta-dashboard.html
│   ├── 전체 콜 현황             → call-status.html
│   ├── 콜 상담                  → call-consultation.html
│   └── 상담 유형                → consultation-type.html
├── 관리자 기능
│   ├── 이슈 처리 관리           → issue-manage.html
│   ├── 키워드 관리              → system/keyword-manage.html
│   └── 분석 기준 관리           → system/analysis-settings.html
├── 리포트
│   └── 리포트 생성기            → report-generator.html
└── 이력 조회
    └── 시스템 로그              → system/logs.html
```
