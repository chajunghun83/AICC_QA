# 커서 AI 사용 가이드 — AICC QA 버그 수정

## 사용 방법

1. 커서 AI 프로젝트에 `AICC_커서_프롬프트.md`와 `AICC_QA_정리.md`를 루트에 넣어 둡니다.
2. 아래 프롬프트를 **단계별로 하나씩** 입력합니다.
3. 각 단계가 끝나면 직접 확인 후 다음 단계로 넘어갑니다.

> ⚠️ 커서에 한 번에 157건을 다 시키면 품질이 떨어집니다.
> 반드시 단계별로 나눠서 진행하세요.

2. 주요 페이지 컴포넌트 파일이 어디에 있는지 매핑해 줘:
   - QA 대시보드
   - 통합 평가 현황
   - 자동 평가 현황

## 🔴 STEP 1. 공통 이슈 — 날짜 선택기 수정 (P0)

```
@AICC_커서_프롬프트.md 의 "공통 이슈 > 2. 날짜/기간 선택 미작동" 참고.

날짜/기간 선택 컴포넌트를 수정해 줘.

[현상]
- 달력에서 날짜 지정 시 선택되지 않고 창이 닫힘
- 월 이동(이전달/다음달)이 되지 않음
- 주간/연간 지정도 작동하지 않음

[기대결과]
- 일/주/월/년 단위 날짜 선택이 모두 정상 작동
- 달력에서 월 이동 가능
- 선택한 기간에 맞게 데이터가 필터링됨

이 컴포넌트는 QA 대시보드, 통합 평가 현황, 자동/수동 평가 현황, 이의 제기 처리함, 비교 분석, 시스템 로그, 나의 평가 결과 등 거의 모든 페이지에서 사용되는 공통 컴포넌트야.
공통 컴포넌트 파일만 수정해서 전체에 반영되도록 해 줘.
```

## 🔴 STEP 2. 공통 이슈 — 센터/팀 필터 수정 (P0)

```
@AICC_커서_프롬프트.md 의 "공통 이슈 > 1. 센터/팀 필터 미작동" 참고.

센터/팀 필터 컴포넌트를 수정해 줘.

[현상]
- 센터를 선택하면 목록이 모두 삭제됨
- 필터가 적용되었다고 표시되지만 실제 데이터는 변경되지 않음
- 팀 선택 시 센터에 맞는 팀 목록이 나오지 않음

[기대결과]
- 센터 선택 시 해당 센터 데이터로 모든 하위 컴포넌트(그래프, 테이블, 리스트)가 필터링
- 팀 드롭다운은 선택된 센터에 종속 (센터 선택 → 해당 센터의 팀만 노출)
- 필터 변경 시 로딩 인디케이터 표시 후 데이터 갱신
- 사용자 관리 페이지에서 대구센터도 포함되어야 함

수정 시 주의사항:
- 센터-팀은 종속 관계: 센터가 바뀌면 팀 목록도 리셋
- 페이지 간 이동 시 선택한 필터 값 유지되어야 함
```

## 🟡 STEP 5. QA 대시보드 페이지 수정

```
@AICC_커서_프롬프트.md 에서 "QA 대시보드" 섹션 참고.
@AICC_QA_정리.md 에서 A-001 ~ A-026 항목 참고.

QA 대시보드 페이지의 버그를 수정해 줘. 주요 수정 사항:

1. 품질 추세 그래프
   - 최근 30일 기준인데 1월 지표가 나옴 → 오늘/어제 기준으로 최근 30일 데이터 표시
   - 센터 변경 시 해당 센터의 QA 점수 지표로 갱신
   - 그래프 클릭 → 통합 평가 현황 이동 시, 선택한 센터와 날짜가 필터에 유지되어야 함

2. 팀별 평균 점수
   - 전체 센터일 때 어떤 센터의 팀인지 불명확 → 센터별로 그룹핑하여 표시
   - 그래프에서 팀 클릭 → 통합 평가 현황 이동 시 해당 센터+팀 필터 유지

3. 긴급 이슈 (섹션명 "관리자 확인 영역"으로 변경 검토)
   - FAIL 건수와 실제 목록 건수 불일치 → API에서 정확한 건수 반환하도록 수정
   - 기준 미달 건수와 실제 목록 건수 불일치 → 동일하게 수정
   - 센터 필터 적용 안 됨 → 적용되도록 수정

4. 점수 분포
   - [미달] 클릭 시 가장 많은 상담 노출됨 → 해당 구간의 상담만 정확히 필터링
   - 센터 필터 미적용 → 적용

5. 최다 감점 항목 Top 5 / 최다 감점 콜 Top 5
   - 클릭 시 해당 상담사/항목으로 필터된 화면으로 이동해야 함
   - 평균 점수 합산값이 실제와 다름 → 계산 로직 확인 및 수정

6. 팀별 평가 현황
   - 서울센터 외 다른 센터 팀 클릭 시 센터 선택부터 다시 나옴 → 이미 선택된 필터로 접속
   - 평가 상담사 수와 하단 상담사 인원 불일치 → 데이터 정합성 확인
```

## 🟡 STEP 6. 통합 평가 현황 수정

```
@AICC_커서_프롬프트.md 에서 "통합 평가 현황" 섹션 참고.

통합 평가 현황 페이지 수정:

1. 상세 분석 탭
   - 긴급 이슈: 2건이라 표시되는데 1건만 노출 → 건수와 목록 동기화
   - 최다 감점 항목: 5콜인데 1콜만 노출 → 동기화
   - 70점 이하 콜: 2콜인데 3콜 뜨고 평균 이상 점수도 포함됨 → 70점 이하만 필터링
   - 감점 항목 클릭 시 해당 상담의 상세 내용을 볼 수 없음 → 클릭 후에도 원래 상담 내용 접근 가능하도록

2. 평가 상세
   - NLP 방식 평가에서 스크립트(상담 내용) 미노출 → 수동 평가와 동일하게 스크립트 표시
   - 전체 목록에서 접근 vs 상세 분석에서 접근 시 하단 UI가 다름(수동 검증/닫기 버튼 유무) → 통일
   - 수동 검증 버튼 클릭 시 시뮬레이션만 뜨고 미작동 → 실제 작동하도록 수정
   - 집계 날짜 표시 추가 (현재 누적인지 특정 기간인지 불명확)
```

## 🟡 STEP 7. 자동 평가 현황 수정

```
@AICC_커서_프롬프트.md 에서 "자동 평가 현황" 섹션 참고.

자동 평가 현황 페이지 수정:

1. 검색조건
   - 신뢰도: 리스트에는 High/Mid/Low인데 검색조건에는 퍼센트로 노출 → 통일 (High/Mid/Low로)
   - 검증 상태 → 필터명을 "수동 검증"으로 변경, 값은 "검증 완료 / 미검증"으로 표시

2. 평가 상세 > 수동 검증
   - 코멘트 작성 후 평가 상세 재진입 시 AI 피드백만 보이고 코멘트 안 보임
     → 검증 완료 상태인 평가 상세 진입 시 수동 검증 코멘트가 바로 노출되어야 함
   - 수동 검증 코멘트 이력이 최근 것만 보임 → 전체 이력 조회 가능하도록 (또는 기획 확인)
```

```

수동 평가 현황 페이지 수정:

1. 페이지네이션 오류
   - 총 12건인데 페이지당 20개 설정임에도 2페이지가 존재
   → 전체 건수가 페이지당 표시 건수 이하이면 페이지네이션 표시 안 함

2. 수동 평가 상세
   - 이미 평가자가 평가를 완료한 경우, AI 피드백 영역 대신 평가자 코멘트가 노출되도록
```

## 🟡 STEP 9. 평가 항목 관리 수정

```
@AICC_커서_프롬프트.md 에서 "평가 항목 관리" 섹션 참고.

평가 항목 관리 페이지 수정:

1. 분류 추가 UI 개선
   - 중분류 추가 버튼 색상이 대분류와 같아 구분 안 됨
   → 대분류 추가 버튼: 주황색 계열, 중분류 추가 버튼: 회색 계열로 차별화

2. 대분류/중분류 제목 수정 불가 → 인라인 편집 또는 편집 버튼 추가

3. 항목 삭제 미작동
   - 시뮬레이션 알림만 뜨고 실제 삭제 안 됨 → 확인 다이얼로그 후 실제 삭제 실행

4. Auto-AI 평가 방식
   - 프롬프트 템플릿 불러오기 미작동 → API 연결 확인 및 수정
   - 테스트 기능 미작동 → API 연결 확인 및 수정
```

## 🟡 STEP 12. 평가 계획 관리 (자동/수동) 수정

```
@AICC_커서_프롬프트.md 에서 "자동 평가 계획 관리", "수동 평가 계획 관리" 섹션 참고.

1. 공통
   - 리스트에 반복 주기 컬럼 추가 (현재 미노출)
   - 대상 검색: 텍스트 검색 → 드롭다운(센터/팀 선택) 형태로 변경
   - 채널 체크박스: 선택/미선택 구분이 어려움 → 선택 시 색상 강조 (파란색 등)
   - 복사 버튼 → "사본 생성"으로 네이밍 변경, 사본은 편집 가능 상태로 생성
   - 삭제 시 확인 다이얼로그(모달) 추가 (현재 바로 삭제됨)

2. 수동 평가 계획 관리 추가 사항
   - 새 계획 추가 시 적용할 평가표 선택 영역 없음 → 추가
   - 평가 계획 상세 편집에서도 평가표 선택 영역 없음 → 추가

3. 새 계획 추가 > 대상 설정
   - 여러 센터의 같은 팀을 한 번에 추가할 수 있는 UI 필요
     (현재는 센터마다 별도 계획을 만들어야 함)
```

   - 미래 날짜 데이터 표시됨 → 오늘 이후 날짜는 표시하지 않음

3. 추세 및 편차 그래프
   - 그래프 범례/설명 없음 → 범례 추가
   - 마우스 오버 시 툴팁 없음 → 툴팁 추가

4. 검색 결과 미출력 (이슈 발생률, 상담사 평균상담 시간, 점수 분포 등)
   → 센터 필터 수정(STEP 2) 후 정상 출력되는지 확인. 안 되면 개별 API 확인
