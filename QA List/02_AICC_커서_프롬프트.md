## 프로젝트 개요
AICC(AI Contact Center) QA 시스템의 QA 테스트 결과 발견된 버그 및 개선 사항을 수정해야 합니다.
아래 페이지별로 정리된 이슈들을 순서대로 수정해 주세요.

## 🔴 공통 이슈 (전체 시스템에 반복적으로 나타나는 문제 - 최우선 수정)

### 1. 센터/팀 필터 미작동 (Critical)
- **영향 범위**: QA 대시보드, 통합 평가 현황, 자동 평가 현황, 수동 평가 현황, 비교 분석, 사용자 관리 등 거의 모든 페이지
- **현상**: 센터를 선택하면 목록이 모두 삭제되거나, 필터가 적용되었다고 표시되지만 실제 데이터는 변경되지 않음. 팀 필터도 센터 필터에 종속되어 함께 미작동
- **수정 요청**: 
  - 센터 선택 시 해당 센터의 데이터로 모든 하위 컴포넌트(그래프, 테이블, 리스트)가 정상적으로 필터링되어야 함
  - 팀 선택은 센터 선택에 종속되어 해당 센터의 팀만 드롭다운에 노출되어야 함
  - 필터 변경 시 로딩 인디케이터 표시 후 데이터 갱신

### 2. 날짜/기간 선택 미작동 (Critical)
- **영향 범위**: QA 대시보드, 통합 평가 현황, 자동/수동 평가 현황, 이의 제기 처리함, 비교 분석, 시스템 로그, 나의 평가 결과
- **현상**: 달력에서 날짜 지정 시 선택되지 않고 창이 닫힘. 월 이동 불가. 주간/연간 지정도 미작동
- **수정 요청**:
  - 일/주/월/년 단위 날짜 선택이 모두 정상 작동해야 함
  - 달력에서 월 이동(이전달/다음달) 가능해야 함
  - 선택한 기간에 맞게 데이터가 필터링되어야 함

### 3. 테이블 정렬 통일 (전체 페이지)
- **영향 범위**: 모든 테이블이 있는 페이지
- **수정 요청**: 
  - 테이블 제목(헤더) 행은 가운데 정렬
  - 텍스트가 긴 컬럼(상담유형, 평가표, 평가표명, 계획명, 이의 항목, 사유, 템플릿명, 접근 범위, 상세 내용)은 좌측 정렬 유지
  - 그 외 모든 컬럼은 가운데 정렬

### 4. 스크롤 누락 (다수 페이지)
- **영향 범위**: 평가 항목 관리 > 편집, 자동 평가표 관리 > 평가표 상세, 수동 평가표 관리 > 평가표 상세, 수동 평가 계획 관리 > 평가 계획 상세
- **현상**: 하단 내용이 있는데 스크롤이 없어서 콘텐츠가 잘림
- **수정 요청**: overflow-y: auto 또는 적절한 스크롤 처리 추가

## 📄 1. QA 대시보드

### [1-1] QA 대시보드 > 날짜 검색

- **현상**: 일/주/월/년간 선택은 가능하나 달력에서 날짜 지정 시 선택되지 않고 창이 닫힘
- **기대결과**: 정상적으로 일자까지 선택하여 확인이 가능해야 함

### [1-2] QA 대시보드 > 날짜 검색

- **현상**: 현재 대시보드가 3월로 고정되어 있음에도 각 그래프 등 이동 시에 최근 상담들이 1월 지표로 노출됨
- **기대결과**: 3월 상담으로 배치되거나 자동으로 설정한 일자에 따라 조정되어야 함

### [1-3] QA 대시보드 > 날짜 검색

- **현상**: 달을 넘기는 것도 되지 않음
- **기대결과**: 이전 달도 확인이 가능해야 함

### [1-4] QA 대시보드 > 센터 선택

- **현상**: 필터가 적용되었다고 뜨나 화면에 보이는 대시보드는 동일함
- **기대결과**: 센터에 맞게 그래프와 상세 내용들이 변경되어야 함 (전체적으로 센터 선택 필터가 적용이 되지 않음)

### [1-5] QA 대시보드 > 센터 선택

- **현상**: 상관없는 센터의 최다 감정 콜 Top5가 노출됨
- **기대결과**: 서울센터를 선택했다면 서울센터의 감점 콜 순위만 나와야 함

### [1-6] QA 대시보드 > 센터 선택

- **현상**: 필터가 적용되었다고 뜨면서 하단에 팀별 평가 현황이 공란으로 나옴
- **기대결과**: 센터에 맞게 평가 현황이 노출되어야 함

### [1-7] QA 대시보드 > 팀 선택

- **현상**: 서울센터를 선택하고 팀을 선택 시에 노출되는 팀이 없음
- **기대결과**: 최다 감점 콜 Top5를 보면 센터마다 팀이 있는 것으로 보이기 때문에 팀이 선택되어야 함

### [1-8] QA 대시보드 > 품질 추세

- **현상**: 최근 30일임에도 불구하고 1월 지표가 나오고 있음
- **기대결과**: 최근 30일에 맞게 오늘 날짜나 어제 날짜를 가장 오른쪽으로 해서 날짜 배치가 되어야 함

### [1-9] QA 대시보드 > 품질 추세

- **현상**: 센터 변경 시에도 동일한 화면 노출
- **기대결과**: 센터가 변경되었다면 그 센터에 맞는 QA 점수 지표가 나와야 함

### [1-10] QA 대시보드 > 품질 추세

- **현상**: 그래프 선택 시 통합 평가 현황으로 들어가나 전체 센터로 설정되어 공란으로 나옴
- **기대결과**: 설정된 센터에 맞게 통합 평가 현황이 노출되어야 함 / 센터를 설정하였다면 통합 평가 현황에서도 자동으로 선택된 센터가 필터에 걸려 검색 화면으로 노출되어야 함

### [1-11] QA 대시보드 > 긴급 이슈

- **현상**: 센터를 변경하였으나 그 센터에 맞는 이슈 건들이 동기화되지 않음
- **기대결과**: 센터에 맞춰 뜰 수 있도록 하거나 필터 값을 변경하면 변경하는 모션이 나와야 함

### [1-12] QA 대시보드 > 긴급 이슈

- **현상**: FAIL(금지어) 3건을 눌렀으나 실제로 금지어 관련 FAIL은 1건임
- **기대결과**: FAIL(금지어) 관련으로 3건이 노출되어야 함 / 그런데 이게 금지어 등을 포함하여 FAIL 건이 전체 노출된다고 하면 맞기는 한 것 같음 (하단에 기준 미달이 있으니까)

### [1-13] QA 대시보드 > 긴급 이슈

- **현상**: 기준 미달 6건인데 실제 목록에서는 8건이 보임
- **기대결과**: 기준 미달 건이 다 보일 건지 이슈에 기준 미달이 적혀 있는 것만 보일 건지 정리가 필요 (위와 동일)

### [1-14] QA 대시보드 > 긴급 이슈

- **현상**: 긴급 이슈라는 표현보다는 다른 대체 단어 필요한 것 같음
- **기대결과**: 나오는 항목이 Fail/기준 미달 건/이의 제기 처리함인데 관리자 확인 영역 정도로 봐야 할 것 같음

### [1-15] QA 대시보드 > 긴급 이슈

- **기대결과**: FAIL/기준미달의 경우 정확한 지표가 필요하거나 리스트에서 바로 볼 수 있는 항목으로 노출될 필요가 있어 보임 > 지금은 AI 피드백에서만 알 수 있으므로

### [1-16] QA 대시보드 > 점수 분포

- **현상**: [미달]이 점수 분포가 제일 적음에도 불구하고 클릭할 시 가장 많은 상담이 노출됨
- **기대결과**: 더 많은 양의 지표를 누를 경우 목록에서도 동일하게 가장 양이 많아야 함

### [1-17] QA 대시보드 > 점수 분포

- **현상**: 센터 필터 당연히 적용 안 됨
- **기대결과**: 센터 선택에 따라 해당 센터 지표로 변경되어야 함

### [1-18] QA 대시보드 > 최다 감점 항목 Top 5

- **현상**: 순위별로 항목이 보이는데 그 항목에 관련한 이슈들이 포함된 상담이 보임
- **기대결과**: 이슈에 뜨는 사항이 가장 큰 점수 감점의 원인인지 확인을 해 봐야 할 듯  / 만약 그렇다면 이 상담 내용 중 공감 표현 부족이 있었구나 하는 지표로 알 수 있겠으나 그게 아니라면 관련한 상담만 노출되어야 함

### [1-19] QA 대시보드 > 최다 감점 항목 Top 5

- **현상**: 2번 선택하여 전체 뜨는 항목의 평균 점수 합산 시 노출되는 점수와 다름
- **기대결과**: 목록에 뜨는 점수 합산하여 평균값 도출 시 69.37점 나옴

### [1-20] QA 대시보드 > 최다 감점 콜 Top 5

- **현상**: 특정 사람을 선택하고 들어갔으나 상담사가 필터가 동일하게 적용되어 있지 않음
- **기대결과**: 동일한 상담사의 이름이 검색된 화면으로 노출되어야 함

### [1-21] QA 대시보드 > 최다 감점 콜 Top 5

- **현상**: 1위 선택하여 접속 시 최수진 씨 말고 강현우 씨도 45점 상담이 있음
- **기대결과**: 최다 감점 콜 Top5로 추린 건데 저 낮은 점수대가 나오면 안 됨

### [1-22] QA 대시보드 > 팀별 평가 현황

- **현상**: 서울센터를 제외한 다른 센터의 팀을 선택할 경우 센터 선택부터 노출됨
- **기대결과**: 서울센터의 팀을 선택한 것과 동일하게 다른 센터의 다른 팀도 이미 선택된 필터로 접속되어야 함

### [1-23] QA 대시보드 > 팀별 평가 현황

- **현상**: 평가 상담사와 하단 상담사 인원 맞지 않음

### [1-24] QA 대시보드 > 팀별 평가 현황

- **현상**: 기준 점수 이하 콜과 하단 정보는 동일하지 않음

### [1-25] QA 대시보드 > 팀별 평가 현황

## 📄 2. 통합 평가 현황

### [2-1] 통합 평가 현황 > 전체 > 검색조건 > 센터

- **현상**: 센터 선택 시 목록 모두 삭제됨
- **기대결과**: 정상적으로 센터에 알맞게 노출되어 함 / 팀 선택도 동일 / 센터가 안 되니까 팀도 안 됨

### [2-2] 통합 평가 현황 > 전체 > 검색조건 > 기간

- **현상**: 일자가 선택되지 않음/달력/주간도 노출되는 게 없음 / 연간 지정도 되지 않음
- **기대결과**: 수정 필요

### [2-3] 통합 평가 현황 > 상세 분석 > 긴급 이슈

- **현상**: 2건이라고 했으나 1건만 노출됨
- **기대결과**: 동일하게 노출되어야 함

### [2-4] 통합 평가 현황 > 상세 분석 > 최다 감점 항목

- **현상**: 5콜이라고 되어 있으나 1콜만 노출됨
- **기대결과**: 동기화 필요

### [2-5] 통합 평가 현황 > 상세 분석 > 최다 감점 항목

- **현상**: 콜을 보기 위해 클릭 시 해당 상담사의 통합 평가 현황으로 들어가짐
- **기대결과**: 그 이후로는 동일한 상담의 내용을 볼 수 없음 (최다 감점 항목이 있어서 클릭하여 들어갔으나 갑자기 없음) - 서울센터 일반 상담팀 임하영

### [2-6] 통합 평가 현황 > 상세 분석 > 70점 이하 콜

- **현상**: 2콜인데 3콜 뜨며 평균 점수가 넘은 것도 뜸 (서울센터>VIP상담팀)
- **기대결과**: 확인 필요

### [2-7] 통합 평가 현황 > 상세 분석 > 70점 이하 콜

- **현상**: 대구센터 > 클레임처리팀 10콜이라고 뜨는데 실제로 7건이 80점 이상임

### [2-8] 통합 평가 현황 > 평가 상세

- **현상**: 통합 평가 결과 전체에서 수동 평가 방식은 스크립트가 노출되나 NLP 방식은 스크립트 없음
- **기대결과**: 스크립트 필요

### [2-9] 통합 평가 현황 > 평가 상세

- **현상**: 전체에서 한 건의 평가를 선택하는 것과 상세 분석에서 팀을 설정하고 상담사의 평가를 선택하는 경우 다르게 노출됨(하단에 수동 검증과 닫기가 없음)
- **기대결과**: 통일성 필요

### [2-10] 통합 평가 현황 > 평가 상세

- **현상**: 상세 분석 > 센터 > 팀 > 상담사 선택 후 평가 상세 누를 시 수동 검증 버튼 노출
- **기대결과**: 시뮬레이션 안내 및 미작동 - 작동되어야 함

## 📄 3. 자동 평가 현황

### [3-1] 자동 평가 현황 > 검색조건 > 센터

- **현상**: 센터 선택 시 목록 모두 삭제됨
- **기대결과**: 정상적으로 센터에 알맞게 노출되어 함 / 팀 선택도 동일 / 센터가 안 되니까 팀도 안 됨

### [3-2] 자동 평가 현황 > 검색조건 > 기간

- **현상**: 일자가 선택되지 않음/달력/주간도 노출되는 게 없음 / 연간 지정도 되지 않음
- **기대결과**: 수정 필요

### [3-3] 자동 평가 현황 > 검색조건 > 신뢰도

- **현상**: 리스트에서는 High Mid Low로 되어 있으나 검색 조건에는 퍼센트로 노출

## 📋 수정 작업 가이드라인

### 작업 우선순위
1. **P0 (Critical)**: 센터/팀 필터 전체 미작동, 날짜 선택 미작동 → 기본 기능 불가
2. **P1 (High)**: 데이터 불일치(건수 미스매치, 점수 합산 오류), 기능 미작동(삭제, 수동 검증, 프롬프트 템플릿)
3. **P2 (Medium)**: 페이지 이동 시 필터 동기화, 그래프-리스트 연동, 네이밍 통일
4. **P3 (Low)**: 테이블 정렬, UI 미세 조정, 체크박스 색상

### 수정 시 주의사항
- 센터-팀 관계는 종속적(센터 선택 → 해당 센터의 팀만 노출)
- 대시보드/상세 페이지 간 이동 시 선택한 필터 값이 유지되어야 함
- 날짜 관련 그래프의 마지막 날짜는 오늘 또는 어제여야 하며, 미래 날짜 데이터는 표시하지 않음
- 페이지네이션: 표시 건수보다 실제 데이터가 적으면 다음 페이지가 생기면 안 됨
- 삭제 기능에는 반드시 확인 다이얼로그(모달) 추가
- 복사 기능은 "사본 생성"으로 네이밍하고, 사본은 '편집 가능' 상태로 생성되어야 함
- 검색 조건의 용어와 리스트의 용어를 통일 (예: ADMIN ↔ 관리자, High/Mid/Low ↔ 퍼센트)

### 각 수정 완료 후 체크리스트
- [ ] 센터 필터 변경 시 하위 모든 컴포넌트 데이터 갱신 확인
- [ ] 팀 필터는 선택된 센터에 종속적으로 동작하는지 확인
- [ ] 날짜 선택(일/주/월/년) 정상 작동 확인
- [ ] 그래프 클릭 → 상세 페이지 이동 시 필터 값 유지 확인
- [ ] 테이블 정렬 규칙 준수 확인
- [ ] 건수/점수 합산값 정합성 확인
